# P0-02 — Educational content authorship and licensing investigation

**Date:** 23 October 2026 (UTC)  
**Scope:** read-only repository and Git-history investigation of P0-02 in `CAMPUSEDUX_ADSENSE_READINESS.md:81-96`. No production database, storage bucket, deployed page, owner contract, or original source manuscript was inspected. Counts below are **seed-intended records**, not verified live records. ## Decision and boundaries

The P0-02 finding is substantiated as a **rights-evidence gap**, not a finding of infringement. Four collections explicitly describe verbatim import from source works whose creators and republication terms are absent from the repository. Java and Python tutorial sources also lack rights evidence. No affected source is documented here as public domain or under a reusable license. Similarity within this repository proves reuse or repetition, not copying from an external rights holder. Attribution alone would not supply missing permission.

The six P0-02 families are AI/ML Notes, Generative AI, Java Interview Questions, Python Interview Questions, Java Tutorials, and Python Tutorial. Blog posts, PDFs, and unrelated course families were checked for a direct P0-02 link; none is established by the cited finding. This does **not** clear those other families for an independent rights audit.

## Provenance and similarity findings

1. **Named but missing manuscripts.** Repository search and `git log --all --name-only` found no committed `AI_ML_Complete_All_10_Modules.md`, `Generative_AI_Full_Syllabus_Detailed_Notes.md`, `core-java-full-course.md`, Java Interview Master Guide, or Python Interview Master Guide. The Python chapter originals are not identified. Earlier `website/CONTENT_PROVENANCE_AUDIT.md:13-137` agrees, but does not supply the absent rights evidence. Git history establishes when SQL entered this repo, not who wrote the upstream manuscripts.
   The earliest file-add commits found with `git log --all --diff-filter=A` were `34d05e0` (6 September 2026, Java/Python tutorial seeds), `f7e4eae` (7 September, AI/ML), `c8b68b9` (14 September, Generative AI), and `e900385` (18 September, Java reconciliation and Python interviews). The Java replacement batches entered at `9466f24` and `2e2b254` (28 September). These checkpoint/feature commits are a repository timeline, not a chain of title for the source texts.
2. **Contradictory Java interview labels.** `0104`–`0107` initially call their set original, but later `0108:11-71` documents source-guide drift and reconciliation. Treat the **current intended public 121** as source-derived, with a mix of verbatim and previously rewritten rows. The **139 archived rows** should remain archived during review; their “original” label is a migration assertion, not independently verified authorship.
3. **Repeated passage evidence.** Direct parsing of 207 Generative AI SQL lesson bodies found nine substantial paragraphs each repeated in all **206** unit bodies, including the paragraph beginning “The important lesson is that the technique is a component of a larger system” (`0069:297,427,557`) and the learning-assistant example (`0069:316,446,576`). The summary body is the exception. This is internal duplication and weakens distinct educational value; it does not identify an external copier or resolve manuscript ownership. The separate P0-03 work is not undertaken here.
4. **Copied or reused examples inside the affected families.** The AI/ML feature-array example headed `# Features: [hours_studied, attendance_percent]` appears at `0068:8083,8329,8565,8802,9043`; a ten-row `X = np.array(...)` dataset recurs at `0068:12409,12921`. A `class Student` example recurs in Python tutorial prose (`0051:2280`; `0055:188,207,226`). These are internal reuse examples. They may be pedagogically reasonable; source rights and individual originality remain open. An exact normalized scan of **870 fenced code blocks of at least 50 characters** across the four lesson grids found **no identical full block across lesson bodies**. That scan does not detect short, reformatted, or semantically copied code.
5. **Original contribution is uneven.** Python seed comments document freshly written MCQ explanations and redesigned deterministic judge problems (`0051:22-34`, `0052:25-48`, `0053:20-58`, `0054:20-45`); the 40 Java rewrites have repo-native lesson files, generated SQL, and a compile/run verification workflow (`content/java/PROGRESS.md:1-24`). These are evidence of editorial/technical work, not proof of ownership of every passage. The other 110 Java baseline bodies, all AI/ML and GenAI transcriptions, and both interview banks have no comparable repository-level rights documentation.
6. **No reliable external match asserted.** The named upstream works are absent and no authenticated publisher copy, publication date, license page, or permission record was supplied. Search-result resemblance or common technical phrasing would not be sufficient to assign a rights holder. External source matching and rights verification are required.

Its [site-readiness guidance](https://support.google.com/adsense/answer/7299563?hl=en) calls for unique, relevant content and original contribution when using external resources. These policies do not decide ownership or whether any particular CampusEduX page will be approved.
