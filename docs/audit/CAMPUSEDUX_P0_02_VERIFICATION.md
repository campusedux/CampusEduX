# P0-02 content rights verification

**Date:** 23 October 2026 (UTC)  
**Scope:** read-only review of the six families in `CAMPUSEDUX_P0_02_CONTENT_LICENSING.md`, their seed and rewrite sources, repository history, and available metadata. This report records **seed-intended** content, not a production inventory. No content, database record, purchase, deployment, or payment was changed. P0-03 was not started.

## Decision

No whole family meets category **A** (documented original ownership) or **B** (documented valid license or permission) on the evidence available. AI/ML Notes, Generative AI, both public-intended interview banks contain documented source-guide transcription and belong in **D** (evidence of *potential* unauthorized reuse) until the source owner and publication rights are established. D is a triage status, **not a finding of infringement**: the absent manuscripts could be owner-authored or licensed. The Java and Python tutorial imports and the 40 Java rewrites are **C** (publication rights unverified). The rewrite files provide stronger evidence of local editorial work than the original Java seed, but repository presence, a style rule, a Git author, and compilation are not a chain of title.

**Retention decision:** preserve all records for evidence. No family can be certified safe for continued public use from this repository alone. Give the currently public verbatim/source-derived material the first owner rights review. If its rights cannot be evidenced promptly, temporary withholding from public display is appropriate for the affected live rows, while preserving existing purchases and entitlements. Withholding from ads alone reduces monetization exposure but does not resolve republication rights. The 40 Java rewrites are candidates for retention after creator/assignment confirmation, reference review, and confirmation that their bodies actually replaced the live baseline. The other 110 Java baseline bodies are only a conditional remainder if both rewrite batches were applied.

Google's current [Publisher Policies](https://support.google.com/adsense/answer/10502938?hl=en) separately list copyright infringement and copied content without added value; its [replicated-content guidance](https://support.google.com/publisherpolicies/answer/11190248?hl=en) describes the added-value question. These policies do not decide who owns a CampusEduX manuscript or whether any particular page qualifies for ads. The [U.S. Copyright Office's overview](https://www.copyright.gov/what-is-copyright/) explains reproduction, derivative and distribution rights; the applicable legal position still depends on the relevant jurisdiction and actual agreements.
