# Answer-first editorial template

Use this for lessons, interview Q&A and guides. Do not mechanically rewrite all existing content to hit a word count.

1. Choose one reader question and one existing canonical URL. Check the keyword map and GSC for overlap.
2. Write one descriptive H1. Add a brief orientation using facts the page actually teaches.
3. Under a question-style H2, answer directly in roughly 40–60 words **when that length answers the question completely**. Define the term, give the condition/context, and state any essential limitation.
4. Follow with a tested example and actual output. Use an ordered list for a sequence, a table for a real comparison, and pros/cons only when a decision benefits from them.
5. Add key takeaways grounded in the page, then links to prerequisite, next lesson and relevant practice. A long article uses the existing TOC and semantic headings; do not skip heading levels for styling.
6. Add FAQs only for real reader questions. Candidate questions in `04-serp-research.md` need validation; none are claimed as extracted PAA. Answers must be visible and match any FAQPage JSON-LD.
7. Cite primary sources adjacent to factual/version-sensitive claims. Attribute quoted material and keep original demonstrations distinct from sourced facts.
8. Use real author/reviewer identity and genuine publication/modification dates. A year in the title requires a named owner and scheduled review; do not refresh dates without substantive changes.
9. Preview on mobile and in raw server HTML. Verify code, tables, links, alt text, one H1 and public/premium boundaries. Do not expose protected answers for crawler access.
10. Have a subject expert review before publishing. BAMS requires a qualified reviewer and source rights. Record the review in the existing editorial workflow.

Example outline (not publishable content): `H1: [Specific concept]`; `H2: What is [concept]?`; direct definition; `H2: How does it work?`; steps; `H2: Example with output`; `H2: Common mistakes`; `H2: Questions students ask`; sources; next learning step.

Google no longer displays FAQ rich results from May 7, 2026; correct schema can remain descriptive but does not promise a special result. Neither this template nor a 40–60-word paragraph guarantees featured snippets, voice answers or AI citations. See [Google documentation updates](https://developers.google.com/search/updates) and [AI guidance](https://developers.google.com/search/docs/fundamentals/ai-optimization-guide).
