# Content gaps and 90-day roadmap

## Existing but weak or unverified
Prioritize current lessons with templated bodies, repeated summaries, missing worked examples or missing citations; the repository already excludes some thin GenAI/coding entries. Do not replace them with mass-generated text. The crawl's low word count flag includes site chrome and is only a review queue. Jobs/projects need actual inventory, not longer empty-state marketing. Resume tools need demonstrated examples and clear limitations. About/team needs verified identity and review responsibilities. Existing blog posts already support dates, author names, TOCs, FAQs and related articles; completeness depends on authored data.

## Hub and spoke ownership
`/learning` → existing course → lesson → related practice and Q&A. `/practice/interview-questions` → Java category → specific topic → relevant lesson. `/blog` → researched guides → the relevant course/tool. `/resume` ↔ `/resume/templates` ↔ resume advice. `/projects` → genuine project/category → project planning guide. `/jobs` → live role → employer; career advice links to the job hub without creating empty role/city doorway pages. Existing lesson, interview and blog related-link systems are retained. Use descriptive topic anchors, not repeated generic “click here”.
